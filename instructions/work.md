# Work profile

When this profile is installed on the work machine, read its current private machine instructions and any private instructions selected by project-context. Archived settings are historical input, not automatically current policy. Shared skills do not replace corporate repository standards, security rules, tracker configuration or tool restrictions. Corporate project rules apply to the corporate target, not every repository on this computer. Personal projects retain their own instructions and may use a separate personal GitHub account; do not assume that account is configured. Keep corporate GitLab identity, corporate email and authentication out of public/personal publication.

For a corporate task launched outside its target checkout, use confirmed applicable private discovery pointers (such as a reviewed bootstrap or repository map) to identify the target first, then resolve that target. The old archive's pointers and blanket loading rules need review rather than automatic reuse. A default/personal result for Pi's launch directory does not override applicable corporate instructions. If the target or affiliation is unclear, clarify it rather than silently selecting corporate or personal policy. Keep corporate material out of the public configuration source.
